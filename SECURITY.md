# Security Policy

Please report suspected vulnerabilities privately through
[Rootly's security page](https://rootly.com/security) or by emailing
security@rootly.com. Do not open a public GitHub issue.

Never include API tokens, alert-source secrets, customer service identifiers,
or Datadog monitor contents in a report sent through a public channel.

Rootly will acknowledge a report within two business days and coordinate
remediation and disclosure with the reporter.
